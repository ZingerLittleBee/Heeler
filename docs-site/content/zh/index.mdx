Heeler 是 [herdr](https://herdr.dev)（Agent 优先的终端运行时）的原生 iPhone 与 iPad 客户端。
它通过 SSH 连接到你的 Host（即运行 herdr 的电脑）。本系列指南介绍如何配置 Host，以及出门在外时如何连接它。

<Callout title="初次使用？">
  如果 Host 是 Mac 或 Linux，并且与 iPhone 或 iPad 处于同一网络（例如同一个 Wi-Fi），最快的方式是[扫码配对](/zh/pairing)。否则请按下面三个步骤操作。如果还不确定选哪种网络，建议从 Tailscale 开始。
</Callout>

## 快速开始

<Cards>
  <GuideCard slug="pairing" locale="zh">安装 Heeler 插件，在 Host 上显示配对码并扫描，无需填写表单。</GuideCard>
</Cards>

## 手动配置

<Steps>
<Step>

### 准备 Host

在运行 herdr 的 Mac 上安装 herdr、开启“远程登录”（Remote Login）、记下 Mac 的 SSH 指纹，并选择 Heeler 的登录方式：[准备 Host](/zh/overlay-networks#准备-host)。如果打算通过 Jump Host 连接，可以先跳过登录方式部分，[Jump Host 配置指南](/zh/vps-jump-host-setup)会一并配置密钥。如果使用的是 Windows Host，请改为参考 [Windows 配置指南](/zh/windows-setup)。

</Step>
<Step>

### 选择连接方式

在同一局域网下，Heeler 可以直接连接 Mac。如果在局域网外，可以使用 [Tailscale](/zh/tailscale) 等 Overlay Network，或使用自己搭建在 Debian / Ubuntu VPS 上的 [Jump Host](/zh/vps-jump-host-setup)。同一台 Host 可以配置[多条路由（Route）](/zh/host-routes)，在家和外出都能无缝切换。

</Step>
<Step>

### 在 Heeler 中添加 Host

打开 **Hosts**，轻点 **Add Host**，然后[填写表单](/zh/overlay-networks#从-heeler-连接)（如果通过 Jump Host 连接，请按[这里的字段值](/zh/vps-jump-host-setup#步骤-13在-heeler-中添加-host)填写）。核对显示的指纹与之前记下的一致后，再轻点 **Trust**；通过 Jump Host 连接时，Heeler 会先询问 VPS 的指纹，再询问 Mac 的指纹。最后[验证连接](/zh/overlay-networks#验证连接)，包括在蜂窝网络下测试。如果已经扫码配对，请改为把 Host 在该网络中的地址添加为[另一条路由](/zh/host-routes#添加路由)。

</Step>
</Steps>

## Overlay Network

Heeler 会直接加入 Overlay Network，iPhone 或 iPad 上无需额外安装 VPN 应用，只需在 Mac 上运行对应服务商的客户端。

<Cards>
  <GuideCard slug="overlay-networks" locale="zh">准备 Host、选择服务商，并从 Heeler 建立连接。</GuideCard>
  <GuideCard slug="tailscale" locale="zh">Heeler 直接加入你的 tailnet，Mac 运行 Tailscale 应用，也可以在终端以免 VPN 方式运行。初次使用推荐从这里开始。</GuideCard>
  <GuideCard slug="zerotier" locale="zh">接入私有 ZeroTier 网络，Mac 运行 ZeroTier One。</GuideCard>
  <GuideCard slug="easytier" locale="zh">无需注册账号；局域网外连接需要自建中继或具有公网入口的 Mac。</GuideCard>
</Cards>

## Cloudflare Tunnel

由 Cloudflare 官方客户端 App 在手机上承载连接，Mac 不开放任何端口；代价是手机上运行一个系统 VPN，适合不想用 Overlay Network 的人。

<Cards>
  <GuideCard slug="cloudflare-tunnel" locale="zh">无需域名的私有网络路由，或在一台 VPS 上运行隧道客户端；最后在 Heeler 中添加一条 Direct 路由。</GuideCard>
</Cards>

## 跳板机（Jump Host）

如果你有一台 Debian 或 Ubuntu VPS，可以让 Mac 保持一条到 VPS 的反向 SSH 隧道，Heeler 通过 VPS 的常规 SSH 端口中转连接。这种方式不需要 Overlay Network 或第三方服务商账号，也不会把 Mac 的 SSH 端口暴露到公网。

<Cards>
  <GuideCard slug="vps-jump-host-setup" locale="zh">按设备分步执行的复制粘贴配置指南，每步均可核对结果。</GuideCard>
  <GuideCard slug="vps-jump-host" locale="zh">信任模型、密钥轮换与迁移到新 VPS 的参考说明。</GuideCard>
</Cards>
