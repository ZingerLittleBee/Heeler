Heeler is the iPhone and iPad console for the coding agents running on your own machines. Your Agents keep working in Herdr TUI, the Herdr desktop app (herdr-core), tmux or Rex, and Heeler connects to them over SSH.

See every Agent on every Host in one console, sorted by who needs you first. Open an Agent to steer its live terminal, or read its conversation as Chat and reply from the Composer. When one goes Blocked or Done, an end-to-end encrypted notification tells you.

WORKS WITH
• Herdr TUI on macOS, Linux and Windows, paired by scanning a code on macOS and Linux
• The Herdr desktop app and herdr-core on macOS, Linux and Windows, following the desktop app's spaces and tabs
• tmux 3.3 or later on macOS and Linux, with sessions, windows and panes as Workspaces, Tabs and Panes, alongside your desktop terminal
• Rex on macOS and Linux (experimental), with its sessions, windows and terminals in the same console
• One Host for each machine: add it once, then switch on each Server it runs

FEATURES
• One Agent Console across all your Hosts, updated live
• Live terminal rendered by libghostty, with native scrollback and touch scrolling
• Chat for Claude Code, Codex, Antigravity CLI, Pi, Oh My Pi, Grok Build and OpenCode, with buttons for Blocked prompts
• Composer with the full iOS keyboard, Agent control keys and Agent Skills
• Voice Input on the device from iOS 26, or with your own OpenAI, DeepInfra, SiliconFlow or compatible speech service
• Changes: every uncommitted file in the Agent's checkout
• Files: browse the Host from an Agent, read-only, and preview, share or save what you find
• Hand Off: give an Agent's work to another Agent, to take over or for a second opinion
• Shell Terminals for every Workspace, with iOS Password AutoFill for password prompts
• Photos and files staged onto the Host, with their paths in your draft
• New Agent with Worktrees, Accounts and Launch Presets
• Usage: Claude Code, Codex and Antigravity CLI Usage Limits and up to 30 days of Token Usage, with widgets
• End-to-end encrypted notifications when an Agent is Blocked or Done, and a Live Activity that tracks your Agents
• Pairing by scanning a code, with an on-device Ed25519 key
• SSH Jump Hosts, several routes per Host, and Tailscale, ZeroTier or EasyTier built in
• Separate light and dark terminal themes

PRIVACY
Heeler has no accounts, analytics or tracking. SSH keys stay in the iOS Keychain. Terminal output, prompts and conversations travel directly between your device and your own Host over SSH. Notification content is encrypted on your Host before it passes through the push relay. Voice Input sends recordings only to the speech service you choose, with your own API key, or keeps them on the device with the On Device service.

REQUIREMENTS
A machine reachable over SSH that runs one of these: herdr 0.7.5 or later on a Mac or Linux machine, or herdr 0.9.3 or later on Windows; the Herdr desktop app or herdr-core; tmux 3.3 or later on a Mac or Linux machine; or a running Rex server on a Mac or Linux machine (experimental). On a Mac or Linux machine running herdr, the included plugin shows a Pairing Code to scan and delivers Agent Notifications. On herdr-core and tmux, the optional Host Helper adds notifications, the Live Activity and Usage on macOS and Linux. Rex has no notifications, Live Activity, Usage or Changes yet.

Heeler is independent and open source. It is not affiliated with the herdr, tmux or Rex projects, or with Anthropic or OpenAI.
