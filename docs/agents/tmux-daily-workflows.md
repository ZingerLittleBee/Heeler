# Daily work on a tmux Host

The comparison target is Heeler connected to **Herdr TUI**. A feature advertised by herdr-core, Rex or a desktop program is a different baseline. The reference checkout is `10148154331e5496afaef9b5b450d514fd1d7d8e`, fetched from `origin/main` on 2026-11-27. The comparison uses [versioned server observations](herdr-compatibility.md), the [Droid matrix](droid-chat-validation.md), the [Devin matrix](devin-chat-validation.md) and ADRs [0044](../adr/0044-tmux-hosts-target-a-running-tmux-server.md), [0045](../adr/0045-tmux-hosts-poll-inventory-and-attach-through-control-mode.md) and [0046](../adr/0046-tmux-program-status-comes-from-heelers-integrations.md). Results in those documents belong to their named versions and candidates.

## Changes under review

- The iPhone and iPad can move a running tmux Pane and set management names for Agents and Tabs. The normal creation, close, worktree, file, attachment and multi-client paths already existed.
- Native Chat checks the age of the current Droid or Devin editor receipt and the selected server again before submitting. It follows an isolated Factory profile, recognizes early Droid trust after a stale status report, and can interrupt a verified Devin turn after an idle report. Devin infers background task IDs from its own recorded shell-launch result. The tmux Chat capability list is independent of herdr-core.
- Host Helper 0.5.13 lets a starting reader record an externally closed pipe. The earlier service, hooks, extensions, Usage, notifications, Live Activities and widgets supply the other Host features tested here.

### Where to review the implementation

- [HostCapabilities](../../Sources/Heeler/Console/HostCapabilities.swift) gates each surface and harness. [ConsoleStore](../../Sources/Heeler/Console/ConsoleStore.swift) owns open details, drafts and pins. [MovePaneSheet](../../Sources/Heeler/Console/MovePaneSheet.swift) carries the presented source session and instance through confirmation.
- [TmuxConsoleProjection](../../Sources/Heeler/Console/TmuxConsoleProjection.swift) validates the inventory and delegates execution. [TmuxHostSession](../../Sources/Heeler/Transport/Tmux/TmuxHostSession.swift) holds the login-resolved executable, socket and current server identity. [TmuxLaunch](../../Sources/Heeler/Transport/Tmux/TmuxLaunch.swift) qualifies a move by session, window and Pane and checks the instance inside the answering tmux command queue.
- [TmuxInventoryLoop](../../Sources/Heeler/Transport/Tmux/TmuxInventoryLoop.swift) reads session, window and Pane fields. [TmuxOrganization](../../Sources/Heeler/Console/TmuxOrganization.swift) projects them into Workspaces, Tabs and Panes, respecting Heeler's Attach marker. Explicit window naming disables tmux automatic naming for that window. A split moved into a new window gets the new window's naming policy. The old window keeps its name and other Panes.
- [TmuxChatTyping](../../Sources/Heeler/Console/TmuxChatTyping.swift), [TmuxComposerSend](../../Sources/Heeler/Console/TmuxComposerSend.swift) and [TmuxComposerStop](../../Sources/Heeler/Console/TmuxComposerStop.swift) share the app's checked write path. [TmuxPaneAttach](../../Sources/Heeler/Transport/Tmux/TmuxPaneAttach.swift) owns size and the lifetime of each control client. The foreground account, process, dedicated conversation and captured editor matter even when the Pane ID has stayed the same.
- [Host Helper's reader](../../plugin/helper/tmux/pipe-reader.js) leaves an occupied user pipe in place. The new worker mark includes its start time. A follower opening during startup gives the reader time to acknowledge EOF before deciding that starting it failed. The [real reader test](../../plugin/test/helper-tmux-pipe-reader.test.js) delays worker startup and closes the pipe from another tmux client.

### Harness boundaries

- Claude Code can use a session registry or launch evidence and its status hook. Codex needs a matching foreground session and independent process ownership. Grok Build can require a manual choice after a thread switch. Pi and Oh My Pi have distinct process/file and extension evidence. Antigravity CLI has its own editor and Stop guards. An Agent row alone establishes recognition.
- Droid needs its session hook and exact JSONL path to follow a conversation. Devin uses the CLI writer's open session lock and bounded SQLite reads. First trust precedes that binding. A verified program, full directory, options and matching visible request are required to act on a card.
- OpenCode 2.0.32 and Amp need different evidence. The OpenCode TUI extension in this checkout publishes route changes to herdr-core's terminal label endpoint. A directory, database or background service can contain sessions belonging to another terminal. Amp's plugin publishes its parent PID, process birth and instance in a registration. The live socket answers with the currently focused thread and a revision. A foreground process and a registration can match while no thread is focused. The tmux program list is maintained independently of herdr-core.
