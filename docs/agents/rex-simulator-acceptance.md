# Rex and Herdr TUI on iPhone and iPad

## Setup

The November 27, 2026 GUI runs used the normal Heeler app, a private macOS SSH listener, one Herdr TUI session and one Rex socket. Both simulators opened Add Host and Add Manually. The fixture authorized each simulator's own public Device Key. Seeded Host records selected those two Servers and pinned the host fingerprint. The first macOS catalog used these seeded records. The Debian runs described below used the normal discovery and first-trust screens. App interactions used XCTest taps, long presses, typing, swipes and orientation changes. Accessibility trees and simulator screenshots recorded the resulting views. The independent Rex observer read each session's active window, each window's focused block, and each shell's foreground directory, PID and size. On the Pencil build the iPad's independent Rex-only Linux wizard found one row, `Rex, Running`. The fixture had the vendor-default socket and no Herdr TUI, herdr-core or tmux installation. After the verified first trust, saving the selected Rex Server produced `Rex, connected` and four successful preflight checks. The screen captures are `pad/pencil-rex-only-{scan,connected,features}.png`.

The same build also exercised the iPadOS window manager. Resizing from the corner produced a floating 375 × 744 pt Heeler window. Opening the system Window Controls, holding Zoom and selecting Left then put Heeler at `(0, 0, 561.5, 744)` on the 1133 × 744 pt display. Heeler used its compact tab bar in that window. The full-width 320/812 pt sidebar and detail measurements above describe the app's own layout. The same half-width position survived relaunch. In the selected long-path shell, the shortcut strip exposed Escape, Tab, arrows, Backspace and Enter. Tapping Enter returned to the fixture prompt in block `block:01a21ccd-29d8-7426-b51c-03ac0c90b846`. An additional attempt to use two apps side by side ended when the simulator reported `Critical process backboardd crashed`. There is no observation of two simultaneously interactive apps. Local receipts are `pad/pencil-rehearsal-os-half-{controls,grid,window-frames}.json` and `pad/drive5.log`.
