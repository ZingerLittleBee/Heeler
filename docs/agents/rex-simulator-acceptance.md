# Rex and Herdr TUI on iPhone and iPad

## Setup

The November 27, 2026 GUI runs used the normal Heeler app, a private macOS SSH listener, one Herdr TUI session and one Rex socket. Both simulators opened Add Host and Add Manually. The fixture authorized each simulator's own public Device Key. Seeded Host records selected those two Servers and pinned the host fingerprint. The first macOS catalog used these seeded records. The Debian runs described below used the normal discovery and first-trust screens. App interactions used XCTest taps, long presses, typing, swipes and orientation changes. Accessibility trees and simulator screenshots recorded the resulting views. The independent Rex observer read each session's active window, each window's focused block, and each shell's foreground directory, PID and size.
