# Rex Chat parity

Heeler recognizes ten Chat programs. On baseline commit
`10148154331e5496afaef9b5b450d514fd1d7d8e`, Rex offers native Chat for Claude Code,
Codex, Pi, Oh My Pi, Factory Droid and Devin CLI on macOS and Linux. Native
Windows offers Claude Code. Chat waits for the Rex server to identify its
kernel. Agent detection, the Terminal surface and its Composer have separate
capabilities. The dated observations below distinguish a terminal accepting a
message from the app opening the right conversation and sending through Chat.

### Private foreground Chat live test

`RexForegroundChatLiveTests/sameDirectoryPeersKeepTheirConversationsAndDesktopSize()`
uses a pinned loopback SSH connection and a second independent Rex client.
Give the iOS Simulator `HEELER_REX_FOREGROUND_CHAT_LAB`, the path to a mode-0600 JSON
fixture. Provide the SSH port, user, seed and pinned fingerprint as
`port`, `user`, `seed`, and `fingerprint`. Supply `rexSocket`, `program`
(`pi`, `omp`, `grok`, `claude` or `codex`), the shared disposable `directory`, and the first terminal's
`rexSession`, `rexBlock`, `firstFile` and its peer's `peerSession`, `peerBlock`,
`peerFile`. Obtain the two absolute JSONL paths independently from seeded CLI
conversations. For Claude Code and Codex, also provide the independently verified UUIDs in `firstID` and `peerID`. The model must answer the unique `REX_LAB_` marker verbatim. For the Claude and Codex control scenarios, set `nativeControls` to `true` and use the fixture provider linked above.
Use fresh clients for each run. The test leaves the first client in a new
conversation and the second in its original conversation.
[Suite](../../Tests/HeelerLiveTests/RexForegroundChatLiveTests.swift), [test selection](testing.md#opt-in-live-suites).

The test first proves it reached two `heeler-lab-` sessions. It compares the
production binder with both independent paths, follows the first conversation
in the Chat store, sends a multiline marker through the checked Composer,
and looks for exactly one prompt and one reply. The desktop starts a new conversation while a second draft is parked (`/clear` for Claude Code, `/new` for the others), then seeds the new conversation from the terminal. Only A may change. If Grok or Codex retains both conversations, Heeler checks the ambiguous binding and the suite deliberately picks old A for reading. A fresh draft addressed to that choice must also be refused. The suite identifies new A from its independent desktop marker before selecting it for reading. Send must refuse the original stale draft,
retain the draft, and leave it absent from all three transcripts. The peer
must also contain zero copies of the sent marker. The independent control
client compares both complete size responses, including its own owner
identity, before and after the Chat operations. These checks use the normal
Rex SSH projection and do not open the Terminal surface.
[Source](../../Tests/HeelerLiveTests/RexForegroundChatLiveTests.swift).

### Devin background shells

The two current macOS clients each ran `exec` twice with `timeout: 0` and no supplied `shell_id`. Four independent Once approvals reached precisely the two intended commands on each backend. Each tool result named a six-character shell ID assigned by Devin. A later `get_output` call named that ID in its arguments and returned the command's own marker and exit code zero. Each acknowledgement and each lookup result was associated with its own structured call ID. The unmodified reader required an explicit `shell_id` on the launch and a longer acknowledgement. This shape omitted both jobs when reopening the transcript. The candidate holds the short acknowledgement until a later, successful typed lookup corroborates it. Duplicate names and ordinary foreground command output cannot claim another launch. [Reader](../../integrations/devin/read-session.py), [reducer](../../Sources/Heeler/Chat/Devin/DevinBackgroundWork.swift), [reader regression](../../scripts/test-devin-session.py), [Swift regression](../../Tests/HeelerTests/DevinChatTests.swift).

## Action boundaries

- **Identity.** Check the current foreground, server instance, and the program's own evidence. An owned Program Status can distinguish Working and Blocked. It does not attribute a transcript. A directory shared by two running clients cannot choose between their sessions. [Rex projection](../../Sources/Heeler/Console/RexConsoleProjection.swift), [process scope](../../Sources/Heeler/Chat/Source/HerdrCoreSessionBinder.swift).
- **Send and stale controls.** The Rex control link serializes each block's writes. A fresh screen check precedes typing. Droid and Devin additionally pin the draft to the displayed session and verify the staged payload before Enter. Their approval and Stop checks have separate call and turn identities. A lost acknowledgement carries an unknown outcome. [Typing](../../Sources/Heeler/Console/RexChatTyping.swift), [delivery](../../Sources/Heeler/Chat/Compose/ChatDeliveryPolicy.swift), [Devin acceptance](devin-chat-validation.md), [Droid acceptance](droid-chat-validation.md).
- **Stop and background jobs.** An Unknown Rex status provides a terminal route for approvals and Stop. An active foreground turn, an independently running command and a child agent can all end separately. Droid's targeted command control verifies the PID and complete command. Devin reads the recorded shell or child identity and leaves job management to its terminal. The current Pi suite does not exercise background job control. [Stop guards](../../Sources/Heeler/Chat/Compose/ChatStopPlan.swift), [background results](devin-chat-validation.md#what-the-cli-showed), [Droid scenarios](droid-chat-validation.md#macos).
- **Attachments.** Chat stages the file over the Host's SSH connection and types its path with the message. An upload or an image accepted by the Terminal Composer alone leaves the native Chat delivery row open. The Pi suite and the gated-harness terminal checks leave open upload cancellation, file recovery or remote attachment removal. [Staging and delivery](../adr/0056-rex-agents-open-the-agent-detail-with-chat.md#update-2026-11-17-attachments), [staging tests](../../Tests/HeelerTests/RexStagingTests.swift).
