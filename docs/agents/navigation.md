# Source map

Start with the row matching the task, then follow its state owner before reading
the concrete transport. The paths are current implementation pointers; dated
research and original ADR rationale remain evidence for their recorded versions.
Use [CONTEXT.md](../../CONTEXT.md) for vocabulary and [testing.md](testing.md) to
choose the verification lane. Update a row when moving its owner or replacing
its contract.

## App entry and Console

- **App/window lifetime:** [HeelerApp](../../Sources/Heeler/HeelerApp.swift) and
  [HeelerAppModel](../../Sources/Heeler/HeelerAppModel.swift) lead to
  [ConsoleView](../../Sources/Heeler/Console/ConsoleView.swift).
- **Agent and Terminal lists:** `ConsoleView` composes
  [ConsoleListPresentationStore](../../Sources/Heeler/Console/ConsoleListPresentationStore.swift),
  [TerminalListView](../../Sources/Heeler/Console/TerminalListView.swift), and
  [ConsoleStore](../../Sources/Heeler/Console/ConsoleStore.swift).
  Both lists name each Host alone (`Host.hostName`, never `Host.displayName`),
  filter by `HostMachine`, and group a Host's Servers into one By Host section
  through `ConsoleHostSectionGroup` in
  [ConsoleHostSectionHeaderPresentation](../../Sources/Heeler/Console/ConsoleHostSectionHeaderPresentation.swift).
  `ConsoleStore` holds each Host behind
  [ConsoleHostProjection](../../Sources/Heeler/Console/ConsoleHostProjection.swift)
  and asks [HostCapabilities](../../Sources/Heeler/Console/HostCapabilities.swift)
  which actions it offers. Focused coverage: `ConsoleListPresentationStoreTests`,
  `TerminalListProjectionTests`, `ConsoleHostSectionHeaderPresentationTests`,
  `ConsoleHostIssueSummaryTests`.
  The corner status tile and its sheet
  ([ConsoleHostIssueRow](../../Sources/Heeler/Console/ConsoleHostIssueRow.swift))
  take one condition for each Host, not for each Server:
  `ConsoleHostStatusPresentation.perHost` in
  [ConsoleHostStatusPresentation](../../Sources/Heeler/Console/ConsoleHostStatusPresentation.swift),
  held as `ConsoleStore.machineIssues`, and the connection sheet they open
  speaks for the Host (`HostConnectionDetailPresentation(group:)`), its Retry
  Now and Stop Connecting reaching every Server the Host has on. Coverage:
  `ConsoleHostConditionsPerHostTests`.
  [HerdrCoreConsoleProjection](../../Sources/Heeler/Console/HerdrCoreConsoleProjection.swift)
  owns a herdr-core Host's; rows start in
  [HerdrCoreOrganization](../../Sources/Heeler/Console/HerdrCoreOrganization.swift),
  a pure builder over the Terminals, the desktop app's
  [document](../../Sources/Heeler/Transport/HerdrCore/HerdrCoreDesktopDocument.swift),
  first-seen directories and `HostServices.checkouts`
  ([script](../../Sources/Heeler/Changes/GitProbe+CheckoutRoots.swift)).
  [TmuxConsoleProjection](../../Sources/Heeler/Console/TmuxConsoleProjection.swift)
  owns a tmux Host's; rows start in
  [TmuxOrganization](../../Sources/Heeler/Console/TmuxOrganization.swift), a pure
  builder over the panes its server lists.
  [HostConsoleProjection](../../Sources/Heeler/Console/HostConsoleProjection.swift)
  owns each Herdr TUI Host's snapshot/delta convergence; start there for missing,
  stale, or resurrected inventory. It builds rows with
  [ConsolePaneRowBuilder](../../Sources/Heeler/Console/ConsolePaneRowBuilder.swift).
  Focused coverage: [ConsoleStoreTests](../../Tests/HeelerTests/ConsoleStoreTests.swift).
- **Agent row fields:** [AgentRowRenderer](../../Sources/Heeler/Console/AgentRowRenderer.swift)
  consumes [AgentRowLayoutStore](../../Sources/Heeler/Console/AgentRowLayoutStore.swift)
  and [AgentRowLayoutResolver](../../Sources/Heeler/Console/AgentRowLayoutResolver.swift).
  Their matching `AgentRow*Tests` suites cover configuration and rendering.
  `AgentCardLines` in [AgentCardView](../../Sources/Heeler/Console/AgentCardView.swift)
  places each row's right side; coverage in `AgentCardChangesTotalsTests`
  ([ChangesBadgeTests](../../Tests/HeelerTests/ChangesBadgeTests.swift)).
  [AgentKindMark](../../Sources/Heeler/Console/AgentKindMark.swift) maps kinds to
  `AgentMarks.xcassets`, and its `AgentStatusAvatar` is the Status Ring that
  leads each `AgentCardView`. Coverage: [AgentKindMarkTests](../../Tests/HeelerTests/AgentKindMarkTests.swift).

- **Copy Pane ID:** `HostCapabilities.copiesPaneID` (Herdr TUI and tmux, whose
  Pane ids their own command lines take) offers
  [CopyPaneIDButton](../../Sources/Heeler/Console/CopyPaneIDButton.swift) in both
  lists' row menus, a Terminal's More menu, and an Agent detail's header menu
  (`backHeaderActions`, an `AgentDetailHeaderAction` with a subtitle).
- **Move to Workspace:** `HostCapabilities.movesPanes` (Herdr TUI) offers
  [MovePaneSheet](../../Sources/Heeler/Console/MovePaneSheet.swift) from the same
  row menus and the Agent detail's header menu. `ConsoleStore.movePane` sends
  [`pane.move`](../../Sources/Heeler/Transport/PaneMove.swift) through
  `HostConsoleProjection.movePane`, carries the pin to the id the Pane has in
  its new Workspace (`PinnedAgentsStore.movePin`), and returns that id for an
  open detail to follow. [Compatibility notes](herdr-compatibility.md) record
  the id change.
- **Hand Off:** `ConsoleStore.offersHandOff` (a live Agent whose program Chat
  reads, on a Host that takes uploads) offers
  [HandOffSheet](../../Sources/Heeler/HandOff/HandOffSheet.swift) from the
  Agents row menu and the Agent detail's header menu.
  [HandOffStore](../../Sources/Heeler/HandOff/HandOffStore.swift) reads the
  conversation through the Agent's `AgentChatStore` as a viewer of its own
  (`ConsoleStore.handOffSource`, which also loads earlier pages), renders it
  with [HandOffRecord](../../Sources/Heeler/HandOff/HandOffRecord.swift), and
  `ConsoleStore.deliverHandOff` stages the file through the receiving Agent's
  `AgentComposerSession` under the mode's message
  ([ADR 0060](../adr/0060-hand-off-stages-a-conversation-record.md)).

  in the separate `HeelerLiveTests` scheme.

## Chat

[AgentChatSurfaceView](../../Sources/Heeler/Console/AgentChatSurfaceView.swift) through
[AgentDetailSurfaceSettings](../../Sources/Heeler/Settings/AgentDetailSurfaceSettings.swift);

`fileStatus`, `listFiles` and `hostHomeDirectory`; OpenCode's conversation
comes through its `queryOpenCode` to `Transport.queryOpenCode`, one bounded
read-only exec per query. Read
[ADR 0024](../adr/0024-native-chat-from-agent-transcripts.md); the formats are
recorded in [Claude Code transcripts](../research/claude-code-transcript-format.md)
and [Codex rollouts](../research/codex-rollout-format.md), and herdr's behavior
in [the compatibility notes](herdr-compatibility.md).

and [OpenCode's session store](../research/opencode-session-store.md) what it was built on.
