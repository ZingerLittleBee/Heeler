# Source map

Start with the row matching the task, then follow its state owner before reading
the concrete transport. The paths are current implementation pointers; dated
research and original ADR rationale remain evidence for their recorded versions.
Use [CONTEXT.md](../../CONTEXT.md) for vocabulary and [testing.md](testing.md) to
choose the verification lane. Update a row when moving its owner or replacing
its contract.

## App entry and Console

- **App/window lifetime:** [HeelerApp](../../Sources/Heeler/HeelerApp.swift) and
  [HeelerAppModel](../../Sources/Heeler/HeelerAppModel.swift) lead to
  [ConsoleView](../../Sources/Heeler/Console/ConsoleView.swift).
- **Agent and Terminal lists:** `ConsoleView` composes
  [ConsoleListPresentationStore](../../Sources/Heeler/Console/ConsoleListPresentationStore.swift),
  [TerminalListView](../../Sources/Heeler/Console/TerminalListView.swift), and
  [ConsoleStore](../../Sources/Heeler/Console/ConsoleStore.swift).
  `ConsoleStore` holds each Host behind
  [ConsoleHostProjection](../../Sources/Heeler/Console/ConsoleHostProjection.swift)
  and asks [HostCapabilities](../../Sources/Heeler/Console/HostCapabilities.swift)
  which actions it offers.
  [HerdrCoreConsoleProjection](../../Sources/Heeler/Console/HerdrCoreConsoleProjection.swift)
  owns a herdr-core Host's; rows start in
  [HerdrCoreOrganization](../../Sources/Heeler/Console/HerdrCoreOrganization.swift),
  a pure builder over the Terminals, the desktop app's
  [document](../../Sources/Heeler/Transport/HerdrCore/HerdrCoreDesktopDocument.swift),
  first-seen directories and `HostServices.checkouts`
  ([script](../../Sources/Heeler/Changes/GitProbe+CheckoutRoots.swift)).
  [TmuxConsoleProjection](../../Sources/Heeler/Console/TmuxConsoleProjection.swift)
  owns a tmux Host's; rows start in
  [TmuxOrganization](../../Sources/Heeler/Console/TmuxOrganization.swift), a pure
  builder over the panes its server lists.
  [HostConsoleProjection](../../Sources/Heeler/Console/HostConsoleProjection.swift)
  owns each Herdr TUI Host's snapshot/delta convergence; start there for missing,
  stale, or resurrected inventory. It builds rows with
  [ConsolePaneRowBuilder](../../Sources/Heeler/Console/ConsolePaneRowBuilder.swift).
  Focused coverage: [ConsoleStoreTests](../../Tests/HeelerTests/ConsoleStoreTests.swift).
- **Agent row fields:** [AgentRowRenderer](../../Sources/Heeler/Console/AgentRowRenderer.swift)
  consumes [AgentRowLayoutStore](../../Sources/Heeler/Console/AgentRowLayoutStore.swift)
  and [AgentRowLayoutResolver](../../Sources/Heeler/Console/AgentRowLayoutResolver.swift).
  Their matching `AgentRow*Tests` suites cover configuration and rendering.
  `AgentCardLines` in [AgentCardView](../../Sources/Heeler/Console/AgentCardView.swift)
  places each row's right side; coverage in `AgentCardChangesTotalsTests`
  ([ChangesBadgeTests](../../Tests/HeelerTests/ChangesBadgeTests.swift)).
  [AgentKindMark](../../Sources/Heeler/Console/AgentKindMark.swift) maps kinds to
  `AgentMarks.xcassets`, and its `AgentStatusAvatar` is the Status Ring that
  leads each `AgentCardView`. Coverage: [AgentKindMarkTests](../../Tests/HeelerTests/AgentKindMarkTests.swift).

  generation capabilities, same-session checks and one-shot delivery. Focused tests:
